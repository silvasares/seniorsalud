## 2. Datos que Recopilamos

SeniorSalud recopila y almacena los siguientes tipos de información:

### 2.1 Datos de Registro
- Nombre completo
- Nombre de usuario
- Número de teléfono
- Edad (opcional)
- Contraseña (almacenada de forma segura)

### 2.2 Datos de Salud
- Presión arterial (sistólica, diastólica)
- Frecuencia cardíaca
- Niveles de glucosa
- Peso
- Temperatura corporal
- Notas personales de salud

### 2.3 Datos Técnicos
- ID de usuario único
- Fecha y hora de las mediciones
- Registros de actividad

---

## 3. Cómo Usamos los Datos

Los datos recopilados se utilizan exclusivamente para:

- Mostrar tu historial de salud
- Generar alertas de valores críticos
- Programar recordatorios de medicación
- Permitir el seguimiento de tu salud cardiovascular

**NO vendemos ni compartimos tus datos con terceros.**

---

## 4. Almacenamiento de Datos

- Los datos se almacenan en **Supabase** (servidores seguros en la nube)
- La conexión está encriptada mediante HTTPS/SSL
- Solo tú puedes acceder a tus datos con tu usuario y contraseña
